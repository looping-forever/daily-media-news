# Description
Considered running a local model inside the GitHub Actions runner so the digest has a model with no external vendor at all, and rejected it on measured grounds. The runner has 2 cores and no GPU, so a 7B model runs at roughly 5 tokens/second, and a multi-GB download plus that throughput cannot fit the run budget. A 1.5B model does fit the time budget but writes headline-echoing summaries, which is exactly the card defect fixed in 7c37a78 and 8f8c85e. A local model is viable only as an extra repair lane on the owner's own machine, never as the primary or the CI fallback.

# Why
Recorded so the option is not re-proposed every few months, and so any future proposal starts from the measurements instead of the idea. It also explains why the backup strategy is built on free hosted families rather than on removing vendors entirely.

# Acceptance Criteria
- The rejection and its measurements are recorded so a future proposal starts from them.
- If runner hardware, throughput or the run budget changes materially, the revisiting is a new record referencing this one rather than an edit that erases the original reasoning.
