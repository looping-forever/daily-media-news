# Description
The steady state the digest is being driven to, in two guarantees. First, news is delivered on every run regardless of AI state, and no card is ever blank: every card carries real digest prose or a clearly labelled publisher summary, as verified in probe runs 42253421839 and 42263580979 and dry run 42188166101. Second, AI degradation is visible and one-line diagnosable rather than discovered as a quietly thinner edition, and no provider a run depends on is a single point of failure.

Scope: the four feature records and the local-inference decision listed as dependencies. Out of scope: news collection changes, social distribution, and reader-facing design.

# Why
This is the owner's goal stated as a target rather than a wish: years of unattended operation in which a failure is low-chance and damages nothing. News collection is already fully independent of any AI, so the remaining work is provider redundancy, self-healing model ids, and a signal that cannot be missed.

# Acceptance Criteria
- A run in which every model fails still publishes, and every card carries real prose or a labelled publisher summary.
- At least two independent AI families are reachable in CI at all times.
- A provider family going dark is detected within a week and reported in one actionable line.
- A retired model id recovers on the next run without losing an edition.
